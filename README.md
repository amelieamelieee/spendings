# Spendings

A personal finance dashboard for tracking spending at a glance, with categories like home, transport, shopping and sports.

**Live site:** https://amelieamelieee.github.io/spendings/

## Files

- `index.html` – the dashboard (built with Tailwind CSS and Iconify icons, loaded from CDN)
- `ph-*.svg` – category and navigation icons
- `image-*.png` – image asset

## Run locally

Open `index.html` in any browser. No build step needed.

## Features

- Add expenses, income and transfers to your savings goal (the **+** button or the quick buttons on the balance card)
- **Insights:** spending by category per month, and the last 6 months compared
- **Transfers:** every transaction, filterable, with delete
- **Profile:** your name, currency, starting balance and savings goal; export/import a backup

Your data is saved in your browser (localStorage), so it stays on that device. Use **Profile → Export backup** to keep a copy or move it to another device.
