# Spendings

A personal finance dashboard for tracking spending at a glance, with categories like home, transport, shopping and sports.

**Live site:** https://amelieamelieee.github.io/spendings/

## Files

- `index.html` – the dashboard (built with Tailwind CSS and Iconify icons, loaded from CDN)
- `ph-*.svg` – category and navigation icons
- `image-*.png` – image asset

## Run locally

Open `index.html` in any browser. No build step needed.
